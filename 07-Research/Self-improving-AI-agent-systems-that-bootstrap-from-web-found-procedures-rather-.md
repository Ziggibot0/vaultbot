## Key Findings
- We show validity of a multiplier bootstrap procedure which is easier to implement and much less computationally demanding than bootstrap procedures based on the transformation model.  [sources: Specification tests in semiparametric transformation models - a multiplier bootstrap approach]
- We propose three new, model-based bootstrap procedures for this problem and show their consistency.  [sources: A Consistent Bootstrap Procedure for the Maximum Score Estimator]
- The new estimator induces two adaptive procedures, i.e., an adaptive Benjamini-Hochberg (BH) procedure and an adaptive Benjamini-Hochberg-Heyse (BHH) procedure.  [sources: Multiple testing with discrete data: proportion of true null hypotheses and two adaptive FDR procedures]
- The adaptive procedures are applied to a study of HIV vaccine efficacy, where they identify more differentially polymorphic positions than the BH procedure at the same FDR level.  [sources: Multiple testing with discrete data: proportion of true null hypotheses and two adaptive FDR procedures]
- Through simulation studies, we show that these procedures are usually more powerful than their non-adaptive counterparts and that the adaptive BHH procedure is usually more powerful than the adaptive BH procedure and a procedure based on randomized p-value.  [sources: Multiple testing with discrete data: proportion of true null hypotheses and two adaptive FDR procedures]
- We prove that the the adaptive BH procedure is conservative non-asymptotically.  [sources: Multiple testing with discrete data: proportion of true null hypotheses and two adaptive FDR procedures]
- Self-Improving Claude Code: A Bootstrap Seed The Hypothesis A single prompt (~1400 tokens), placed in a project's .claude/CLAUDE.md , can bootstrap a Claude Code instance into a self-improving system — one that captures learnings, extracts patterns, evolves its own configuration, and gets meaningfully better at helping its user with each session.  [sources: Self-Improving Claude Code: A bootstrap seed prompt that evolves into a ...]
- In a simulation study we demonstrate the superior performance of the procedure in comparison with the competitors from the literature.  [sources: Specification tests in semiparametric transformation models - a multiplier bootstrap approach]
- In this current work, second order results of this non-naive bootstrap method have been investigated.  [sources: Second Order Correctness of Perturbation Bootstrap M-Estimator of Multiple Linear Regression Parameter]
- Additionally, we show that the Perturbation Bootstrap continues to be S.O.C. when the errors $ε_i$'s are independent, but may not be identically distributed.  [sources: Second Order Correctness of Perturbation Bootstrap M-Estimator of Multiple Linear Regression Parameter]
- By incorporating these examples, Bootstrap Few-Shot enhances the model’s performance on a wide range of tasks.  [sources: A Comparative Study of DSPy Teleprompter Algorithms for Aligning Large ...]
- These findings establish perturbation Bootstrap approximation as a significant improvement over asymptotic normality in the regression M-estimation.  [sources: Second Order Correctness of Perturbation Bootstrap M-Estimator of Multiple Linear Regression Parameter]
- Extensive experiments on KITTI and TUM RGB-D datasets verify the superiority of our self-improving geometry-CNN framework.  [sources: Pseudo RGB-D for Self-Improving Monocular SLAM and Depth Prediction]
