## Key Findings
- The system employs four specialized agents: a natural language interpreter that converts user requests into physics-based descriptions; a technical requirements generator that produces scaled simulation parameters; a physics code generator with automated self-correction; and a physics validator that implements perceptual self-reflection.  [sources: Perceptual Self-Reflection in Agentic Physics Simulation Code Generation]
- In our tests, the virtual agents responded within 2-4 seconds after the user query.  [sources: Design of Seamless Multi-modal Interaction Framework for Intelligent Virtual Agents in Wearable Mixed Reality Environment]
- Here we study how to design artificial agents that can interact naturally with humans using the simplification of a virtual environment.  [sources: Creating Multimodal Interactive Agents with Imitation and Self-Supervised Learning]
- Grounded interaction here has the form of examples that consists of common instances, for which the agents are expected to have similar knowledge.  [sources: Establishing Shared Query Understanding in an Open Multi-Agent System]
- Communication is an effective mechanism for coordinating the behaviors of multiple agents, broadening their views of the environment, and to support their collaborations.  [sources: A Survey of Multi-Agent Deep Reinforcement Learning with Communication]
- Agents can communicate various types of messages, either to all agents or to specific agent groups, or conditioned on specific constraints.  [sources: A Survey of Multi-Agent Deep Reinforcement Learning with Communication]
- We propose a method that allows to develop shared understanding between two agents for the purpose of performing a task that requires cooperation.  [sources: Establishing Shared Query Understanding in an Open Multi-Agent System]
- In this example, the agents want to query each other, while representing different databases, defined in their own ontologies that contain different and incomplete knowledge.  [sources: Establishing Shared Query Understanding in an Open Multi-Agent System]
- In the field of multi-agent deep reinforcement learning (MADRL), agents can improve the overall learning performance and achieve their objectives by communication.  [sources: A Survey of Multi-Agent Deep Reinforcement Learning with Communication]
- We present a multi-agent framework for generating physics simulation code from natural language descriptions, featuring a novel perceptual self-reflection mechanism for validation.  [sources: Perceptual Self-Reflection in Agentic Physics Simulation Code Generation]
- Our method focuses on efficiently establishing successful task-oriented communication in an open multi-agent system, where the agents do not know anything about each other and can only communicate via grounded interaction.  [sources: Establishing Shared Query Understanding in an Open Multi-Agent System]
- The perceptual self-reflection architecture demonstrates substantial improvement over single-shot generation baselines, with the majority of tested scenarios achieving target physics accuracy thresholds.  [sources: Perceptual Self-Reflection in Agentic Physics Simulation Code Generation]
- Agents should be able to communicate with each other freely using different communication protocols, constituted by communication acts.  [sources: A mechanism for discovering semantic relationships among agent communication protocols]
