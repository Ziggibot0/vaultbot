## Key Findings
- Auto-Dreamer decouples fast per-session memory acquisition from slow cross-session consolidation.  [sources: Auto-Dreamer: Learning Offline Memory Consolidation for Language Agents]
- We present preliminary results about Legistix, a tool we are developing to automatically consolidate the French and European law.  [sources: Towards an Automatic Consolidation of French Law]
- Inspired by complementary learning systems theory, we propose Auto-Dreamer, a learned offline consolidator for language-agent memory.  [sources: Auto-Dreamer: Learning Offline Memory Consolidation for Language Agents]
- Even under a strong threat model where the intervention remains active throughout optimization and generation, recovery remains possible.  [sources: SAE Interventions are Unreliable: Post-Intervention Recovery of Suppressed Behavior]
- To rule out that recovery simply undoes the intervention, we use encoder-orthogonal updates for single-layer interventions and the corresponding feature-map Jacobian in the cross-layer setting.  [sources: SAE Interventions are Unreliable: Post-Intervention Recovery of Suppressed Behavior]
- We train Auto-Dreamer via GRPO, using end-to-end agent performance as the reward signal to learn how to consolidate memories acquired through fast online experience.  [sources: Auto-Dreamer: Learning Offline Memory Consolidation for Language Agents]
- Recent latent-space defenses increasingly rely on these decompositions, assuming that identified "unsafe" SAE features serve as actionable handles for monitoring and intervention.  [sources: SAE Interventions are Unreliable: Post-Intervention Recovery of Suppressed Behavior]
- Across TPP, unlearning, IOI, and refusal steering experiments, this stress test reveals recoverable behavior despite successful feature-level intervention.  [sources: SAE Interventions are Unreliable: Post-Intervention Recovery of Suppressed Behavior]
- The primary motivation is to obtain a novel summarization of the effect of various treatments which would guide practitioners towards better decision regarding which intervention to choose.  [sources: Stochastic Intervention]
- These results expose a gap between feature-level control and behavioral completeness: SAE features can support causal intervention, but controlling them does not guarantee control over the underlying behavior.  [sources: SAE Interventions are Unreliable: Post-Intervention Recovery of Suppressed Behavior]
- This article discusses the application of stochastic intervention to find the optimal treatment distribution yielding a high value of expected potential outcome under the setting where the number of treatments is allowed to vary with $n$.  [sources: Stochastic Intervention]
- Instead of creating manually a full consolidated version of a text at each modification date, Legistix generates automatically programs from legal documents written in natural language to automatically create the consolidated versions.  [sources: Towards an Automatic Consolidation of French Law]
- Retrieval-augmented and structured memory methods record per-session observations effectively, but often couple acquisition and consolidation into a single online process, leaving the agent without a global view across sessions to discover recurring patterns, abstract shared procedures, or prune redundant entries.  [sources: Auto-Dreamer: Learning Offline Memory Consolidation for Language Agents]
